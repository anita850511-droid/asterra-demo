# Asterra v4.5 — 角色建立器 UX 可測試版

這版的目的，是先測試「高品質 Asterra 美術介面 + 捏角操作流程」，不是宣稱已完成正式 3D 捏角資產。

## 已可測試
- 點左側分類後，右側只顯示該分類參數。
- 臉型 12、膚色 16、眼睛 16、眉毛 12、鼻子 12、嘴型 12、髮型 20、髮色 20、瞳孔 20、身形 12、服飾 10。
- 各類別使用 01、02、03… 編號，不用縮圖列。
- 臉部分類自動顯示正面臉部；身形／服飾顯示正面全身。
- 身形包含身高、頭身比、肩寬、腰臀、軀幹、手臂、腿長、腿部粗細、肌肉感等參數。
- 隨機生成、重置、撤銷、重做。
- 設定會儲存在瀏覽器 localStorage。

## 目前刻意保留的限制
目前預覽使用已確認的 Asterra 高品質美術概念圖，因此：
- 臉型／身形滑桿只做近似比例預覽。
- 膚色／髮色／瞳色有近似色彩效果。
- 髮型 01～20、服飾 01～10 已完成 UI 與資料儲存，但尚未有 20 組正式 3D Hair Mesh / 10 組 Outfit Mesh，所以不會真的換模型。

這樣可以先確認分類、參數數量、操作節奏、畫面配置與鏡頭切換，再投入正式 3D Base Mesh、Morph Targets、髮型與服裝資產。
