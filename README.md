# Asterra Demo v3 — 市政廳美術場景串接版

這版不是再用 CSS 假裝畫美術，而是直接把已確認方向的「市政廳 2.5D 視覺稿」串進網站，先測真正遊戲畫面的感覺。

## 這版可以測
- 從城市地圖點「潮港市政廳」
- 移動時仍使用畫面上方的小型進度條，不跳中央彈窗
- 抵達後直接進入高質感市政廳場景
- 可以直接點畫面裡的：
  - 接待員
  - 等候的居民
  - 守衛
  - 市政櫃台
  - 公告欄
- 直接點角色就會進入當面互動，不必一定點側邊欄
- 圖中右側部分按鈕也放了可點擊區
- 點「離開市政廳」會回到城市地圖
- 對話目前仍是本地模擬，不使用 GPT / API
