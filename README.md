# Asterra v4.2 — 市政廳首次居民流程

這版把市政廳從「背景圖上的假按鈕」改成實際流程原型：

- 第一次進入會自動引導前往潮港市政廳辦居民證件登記。
- 服務櫃台如果有人使用，要先抽號碼牌。
- 取號後可選擇坐在候位區，或站到市政資訊公告欄前查看公告。
- 角色位置使用「活動位置槽」直接切換，不做貼紙滑行動畫。
- 叫號後玩家再前往服務櫃台；房產服務與土地／建設業務都在櫃台內，不再單獨漂在場景。
- 公告欄互動點直接放在畫面中的市政資訊公告欄上。
- 朝野在咖啡館會維持自己的活動，不會因玩家進入就自動搭話。
- 右側有「重置首次流程」，方便重新測試。

目前叫號等待時間為 9 秒，只是原型壓縮，用來驗證流程；正式版會由世界時間與服務狀態決定。
