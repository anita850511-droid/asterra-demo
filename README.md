# Asterra v4.3 — 登入＋角色建立原型

這一版在 v4.2 市政廳流程上加入可試用的「本機登入／角色建立」系統。

## 這版可以試什麼

- 第一次開啟會先看到 Asterra 登入入口。
- 新角色可以調整：
  - 膚色
  - 眼型
  - 眉型
  - 鼻型
  - 嘴型
  - 髮型
  - 髮色
  - 瞳孔顏色
  - 基礎服飾
- 外觀會儲存在瀏覽器 localStorage。
- 重新整理後可以「繼續目前角色」或「修改目前外觀」。
- 角色建立階段 **不填姓名、生日**。
- 進入潮港城後仍以「未登記居民」身分活動。
- 首次流程會自動引導到潮港市政廳。
- 到居民登記櫃台時才輸入姓名、生日、自我稱呼，並取得居民編號。
- 玩家在市政廳候位區／公告欄／櫃台，會使用同一套捏角外觀的角色圖層；坐下時會切換成坐姿原型。

## 注意

這是功能原型，不是真正的雲端帳號登入。角色與遊戲進度目前只存在使用者當下的瀏覽器。

角色目前使用 SVG 紙娃娃模型來驗證「同一角色可換姿勢而不重新生成圖片」的架構，最終美術之後可以替換成正式 2D 骨架／3D 角色系統，而不需要改掉玩家外觀資料模型。

## GitHub Pages 上傳

把 ZIP 解壓後的所有內容直接上傳到 repo 根目錄，讓 `index.html` 覆蓋舊檔案。這版使用新的：

- `styles-v43.css`
- `app-v43.js`

因此能避開舊 v4.2 JS/CSS 快取。
