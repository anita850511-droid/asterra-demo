# Asterra v4.6 — 即時角色預覽測試版

這版修正 v4.5 最大問題：角色預覽不再只是靜態圖片。

## 現在會真的動的項目
- 臉寬、臉長、下顎、顴骨、下巴
- 眼睛大小、寬度、眼距、眼尾角度、眼睛高低
- 眉毛位置、角度、長度
- 鼻子長寬與鼻尖
- 嘴寬、上下唇、嘴角
- 膚色、髮色、瞳色
- 身高、頭身比、肩寬、腰臀、腿部比例等身形參數
- 臉型／眼型／眉型／鼻型／嘴型／身形編號 preset 會產生不同的即時變形
- 髮型 preset 目前用髮量／長度／分線變形驗證互動
- 服飾 preset 目前用服裝色調與輪廓變化驗證互動

## 仍不是正式角色模型
目前用 WebGL 對高品質角色概念圖做即時影像變形，目的是確認捏角 UI 和參數手感。
它不是正式 3D 角色，因此髮型與服裝還不是真正獨立 Mesh，也不能直接拿來做走路／坐下動畫。

正式版會把相同 character recipe 交給可骨架動畫的 3D Base Mesh + Morph Target 系統。
