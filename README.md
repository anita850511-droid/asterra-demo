# Asterra v4 · 動態城市架構原型

這一版開始把「美術概念圖」轉成可持續擴充的城市結構：

- 潮港城使用乾淨底圖，建築名稱氣泡由 HTML 動態疊加，因此名稱、位置與狀態不是畫死在圖片裡。
- 地圖上只顯示建築名稱，不顯示建築說明。
- 點建築名稱氣泡後，頂端顯示小型移動進度條；抵達後自動進入地點場景。
- 港口咖啡館與市政廳使用目前核准的場景視覺。
- 人物以獨立圖層存在；只有世界狀態判定人在該地點時才出現。
- 人物的點擊區域就是可見人物／名稱氣泡，不建立大型透明熱區。
- 建築資料與地塊資料分離。建築可有 open / closed / construction / demolished 狀態，之後可接世界事件引擎。
- `parcels` 保留土地，`buildings` 代表土地上目前存在的建築；未來即使建築拆除，地塊仍可重新開發。

目前未接 GPT/API，也未用定時亂數事件假裝正式世界 AI。後續應先接世界狀態與建築生命週期，再做 AI 決策層。
