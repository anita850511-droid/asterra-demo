# Asterra v4.4 — 3D 角色建立系統（第一個可試用底座）

這版正式停止使用 v4.3 的 SVG 紙娃娃，改成瀏覽器中的即時 3D 角色建立器。

## 已完成

角色建立時可以即時變更同一個 3D 角色：

- 臉型：12 種 + 臉寬／下顎／眼距細調
- 膚色：16 種
- 眼型：16 種
- 眉型：12 種
- 鼻型：12 種
- 嘴型：12 種
- 髮型：20 種
- 髮色：20 種
- 瞳孔顏色：20 種
- 基礎服飾：10 種
- 角色可拖曳旋轉、滾輪縮放
- 可切換正面／3/4／側面
- 可隨機外觀

外觀存檔後，同一份外觀參數會繼續用在 Asterra 世界中。
市政廳候位、查看公告欄、站在櫃台時，會從同一個 3D 角色產生不同姿勢的透明人物快照，不再為每個動作重新生成另一個人。

玩家建立外觀時仍然沒有姓名。第一次進城後會自動引導到潮港市政廳，排隊後才在居民登記流程輸入姓名、生日等資料。

## 美術狀態

v4.4 是「自有 3D 角色架構」的第一個技術／視覺底座。這次已不再是假紙娃娃，但目前的頭部、五官、髮型與服裝仍為程式化模型。後續會把這套可捏參數接到正式 Asterra Base Mesh、正式髮型 Mesh、材質與服飾資產，目標美術是專案已確定的精緻半寫實日系 CG。

重要的是：之後更換正式模型時，角色資料結構（臉型、膚色、五官、髮型、顏色、服飾）可以保留，不必再把登入流程推翻。

## GitHub Pages

把 ZIP 解壓後的內容全部上傳到 `asterra-demo` repo 根目錄，讓 `index.html` 覆蓋舊檔案。

此版使用：
- `index.html`
- `styles-v44.css`
- `app-v44.js`
- `assets/`

3D 引擎使用 Three.js ES module，第一次開頁面需要可連線到 jsDelivr CDN。正式版之後會把引擎檔與角色資產一起打包，避免依賴外部 CDN。

## 建議測試流程

1. 建立新角色。
2. 分別切換臉型、眼型、髮型與服飾，確認是同一個 3D 人物即時改變。
3. 拖曳角色查看側面與 3/4 角度。
4. 儲存角色進入 Asterra。
5. 等待自動前往潮港市政廳。
6. 抽號碼牌後選「坐在候位區等待」，確認畫面中的玩家使用相同外觀的坐姿。
7. 改選「查看市政資訊公告欄」，確認玩家切換成閱讀姿勢。
8. 叫號後前往櫃台，完成姓名與生日登記。
